# そろばん練習Webアプリ (Soroban Learning Web App)

子どもが楽しく5桁までの足し算・引き算を練習できる、ポップでインタラクティブなWebアプリケーションです。

---

## 概要

本アプリは、そろばんを使った暗算・計算力向上を目的とした子ども向けのWeb教材です。
画面上に自動生成される計算問題をそろばんで計算し、「できた！」ボタンを押すことで正解判定を行います。正解時にはファンファーレや紙吹雪アニメーション、スター（星）の獲得など、お子様が夢中になって取り組める工夫を多数取り入れています。

---

## 主な機能・特徴

- **5桁までの足し算・引き算対応**:
  - 1〜5桁（最大99,999）の範囲でランダムに問題を出題。
  - お子様の学年や熟練度に合わせて選べる3段階の難易度設定（1〜2けた / 3〜4けた / 5けたまで）。
- **「できた！」判定と3秒後の自動次問題遷移**:
  - 「できた！」ボタンでそろばんの値を判定。
  - 判定後、3秒間のカウントダウンバーが表示され、自動で次の問題へ進みます（「つぎへ」ボタンでスキップも可能）。
- **位取り（桁）ガイド**:
  - 各桁の上に「万・千・百・十・一」のラベルを表示し、位取りの概念を視覚的に理解しやすくしています。
- **そろばん初心者向けガイド・使い方チュートリアル（📖 つかいかた）**:
  - 各部の名前（梁・一だま・五だま・定位点）の図解解説。
  - 1〜4の数の入れ方・払い方（指使いの基本）。
  - 五だま（5）の使い方と5〜9の数の表し方。
  - 10の繰り上がりの考え方（10のなかま）。
  - ステップごとに実際に玉を動かして試せるインタラクティブミニミッション機能付き。
- **本格的なそろばんUI & スワイプ・ドラッグ操作性**:
  - 伝統的な菱形（バイコニカル）形状の玉デザイン。
  - 定位置（千の位・一の位の点）を配置。
  - 一玉（4個）と五玉（1個）のクリック/タップ操作に加え、**指で弾くスワイプ・ドラッグ操作**にも完全対応。
  - リセット（ご破算）時の左から右へ波状に玉が払われるスムーズな連動アニメーションと木製スイープ音。
- **がくしゅうきろく・統計グラフ機能（📊 きろく）**:
  - 解いた問題数、正解率（%）、最高連続正解数、平均回答スピード（秒）を自動記録・可視化。
  - レベル別（1〜2けた、3〜4けた、5けたまで）の正解率プログレスバー表示。
  - 直近のチャレンジ履歴タイムライン表示。
  - `localStorage` による学習データの自動保存（ブラウザを閉じても記録を維持）。
- **キーボードショートカット対応**:
  - スペースキー: できた！/ 次へ
  - Cキー: リセット（ご破算）
  - Gキー: つかいかたガイド
  - Hキー: がくしゅうきろく
  - Escキー: モーダルを閉じる
- **Web Audio APIによる本格的な木製サウンド演出**:
  - 樺・柘植のそろばん玉が梁や枠に衝突する音響物理を再現した、リアルな木製クリック音（高周波アタックノイズ・木製共鳴周波数・減衰特性のモーダル合成）。
  - 複数玉の一括操作時における微細なタイムラグ衝突音（「カチャッ」「パチチッ」）および、リセット（ご破算）時の心地よい木製スイープ音。
  - 正解時のファンファーレ音と失敗時のやさしいチャイム音。
  - ミュート（おとのON/OFF）切り替えボタン付き。
- **ゲーミフィケーション要素**:
  - 正解時の紙吹雪（Confetti）エフェクト。
  - 獲得した「ほし（⭐）」と「れんぞく正解（🔥）」のカウンター表示。
- **マルチデバイス対応（レスポンシブ）**:
  - PCの大画面からスマートフォン（iPhone / Android）の縦画面まで、スクロールなしで快適に操作できるレスポンシブデザイン。

## ファイル構成

本プロジェクトは外部ライブラリに依存せず、標準的なWeb標準技術（HTML5 / CSS3 / Vanilla JavaScript）のみで構築されています。

```text
soroban/
├── index.html   # アプリケーションのHTML構造・DOM要素
├── style.css    # ポップなデザインシステム、そろばん描画、レスポンシブレイアウト
├── script.js    # 出題エンジン、そろばん計算ロジック、Web Audio音源、アニメーション制御
└── README.md    # 本ドキュメント
```

## 使い方・動作方法

### 1. ブラウザで直接開く場合
特別なビルド処理や事前インストールは不要です。
`index.html` ファイルをダブルクリックするか、お使いのWebブラウザ（Chrome, Safari, Edge等）にドラッグ＆ドロップして開くだけで起動します。

### 2. ローカルWebサーバーで実行する場合（推奨）
Visual Studio Code の `Live Server` 拡張機能や、Pythonの簡易サーバー等を利用してアクセスすることも可能です。

```bash
# Python 3 をご利用の場合
python3 -m http.server 8000
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
